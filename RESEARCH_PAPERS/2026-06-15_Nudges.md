# LLM agents are sensitive to nudges

## About

Title : AI agents are sensitive to nudges

Link : <https://www.pnas.org/doi/10.1073/pnas.2537030123>

Researchers : Manuel Cherep, Pattie Maes, Nikhil Singh

Institution : MIT Media Lab

Date : 06/15/2026

Code : <https://github.com/PapayaResearch/nudging>

## Synthesis

A nudge is any change to choice architecture that predictably alters behavior without forbidding options or changing incentives. Their average effect on humans is modest (~2% in large-scale RCTs). This paper tests 8 leading LLMs on a multi-attribute decision task under four nudge types, using human behavior as a calibrated baseline. Models tested: GPT-3.5 Turbo, GPT-4o Mini, GPT-4o, o3-Mini, Gemini 1.5 Flash, Gemini 1.5 Pro, Claude 3 Haiku, Claude 3.5 Sonnet.

Default option nudge (acceptance probability with vs. without nudge):

| Model | Without nudge | With nudge |
| --- | --- | --- |
| Humans | 0.51 | 0.88 |
| GPT-4o, Claude 3 Haiku, o3-Mini | ~0.50 | 1.00 |
| GPT-3.5 Turbo | ~0.50 | 0.99 |
| Claude 3.5 Sonnet, Gemini 1.5 Pro | ~0.50 | 0.89-0.91 |

Suggestion nudge (early suggestion acceptance):

| | Humans | Claude 3 Haiku | GPT-4o / Gemini 1.5 Flash |
| --- | --- | --- | --- |
| Acceptance probability | 0.37 | 0.99 | 0.62-0.64 |

Net earnings measure overall task performance.       
Reference points: random play = 150 pts, perfect play = 183.64 pts, humans without nudge = 160.91 pts.

| Model | Without nudge | With optimal nudge |
| --- | --- | --- |
| Humans | 160.91 | 174.48 |
| GPT-3.5 Turbo | 146.50 | -- |
| GPT-4o Mini | 142.95 | -- |
| GPT-4o | 162.70 | -- |
| Claude 3.5 Sonnet | 163.03 | 176.45 |
| o3-Mini | -- | 180.18 |

Without nudges, GPT-3.5 Turbo and GPT-4o Mini fall near the random baseline, while GPT-4o and Claude 3.5 Sonnet reach human level. With optimal nudges, o3-Mini and Claude 3.5 Sonnet actually exceed human performance.

Critically, models follow nudges at similar rates whether the nudge is optimal or suboptimal. Humans discriminate; LLMs largely do not. Neither chain-of-thought prompting nor few-shot human data reliably fixes this. The implication: any actor controlling the framing of the environment an LLM agent operates in can shift its decisions without touching the model and without adversarial intent.
